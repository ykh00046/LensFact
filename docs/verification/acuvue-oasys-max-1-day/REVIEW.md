## 3. 한 번 더 봐야 할 것

### 3-1. UV 충돌 — 이 제품의 핵심 쟁점 (필수 재검토)

| 출처 | 인쇄된 원문 |
| --- | --- |
| 한국 공식 제품 페이지 | `자외선 차단 1등급 - UVA 90%, UVB 99% 이상 차단` (각주 `# UVA 316~380nm, UVB 280~315nm 범위에서 측정`) |
| ACUVUE Technical Specification Guide 1쪽 1열 | `Blocks 100% of UVB` / `& 99.9% of UVA` (행 제목 `Approximate UV Blocking*†`) |

- **한국 페이지의 UV 문장은 아큐브 오아시스 원데이 페이지와 글자까지 완전히 같다.**
  그러나 글로벌 사양에서 두 제품의 UV 숫자는 다르다(MAX `100% / 99.9%` vs 원데이 `>99.9% / 96%`).
  즉 한국 표기는 두 제품을 구분하지 않고 글로벌 표기는 구분한다. 이 비대칭 자체가 독자에게 유용한 정보다.
- 한국의 `자외선 차단 1등급`이 어떤 등급 체계인지, 글로벌의 근사 차단율과 어떻게 대응하는지는
  **두 문서 어디에도 설명이 없다.** 값만 병기하고 해석하지 않았다.
- MFDS 등록 모델명에 UV 관련 문구가 **없다.** UV 차단 기능 자체의 한국 **허가 원장** 근거는 없고,
  한국 측 근거는 제품 페이지 표기 하나뿐이다.
- 판단 필요: 비교표 UV 행에 두 원문을 어떻게 배치할지. 파일럿의 오아시스 원데이 UV 충돌 표기 방식과 맞추는 것이 좋다.

### 3-4. 원문 표기 함정 (충돌 아님, 그대로 기록만)

- **한국 페이지 HTML의 `8.5`(14회)·`9.0`(66회)는 80회 전부 로고 SVG의 path 좌표다.**
  `<svg>` 블록 밖에서는 0건. **이 제품의 실제 BC가 8.5/9.0이라 오독 위험이 크다.** 스펙으로 쓰지 않았다.
- `senofilcon`은 PDF에서 `fi` 합자 글리프(U+FB01)로 인쇄돼 추출 문자열이 `senoﬁlcon A`가 된다. 인쇄된 단어는 `senofilcon A`다.
- Dk/t 원문 `121 x 10-9 (-3.00D)`에서 `-9`는 인쇄물 위첨자다. 값은 `121 × 10⁻⁹`로 표기했다.
- 이 열의 UV는 UVB·UVA 모두 **부등호 없이** `Blocks 100% of UVB` / `& 99.9% of UVA`로 인쇄된다.
  부등호가 붙는 것은 같은 표의 오아시스 원데이 열(`>99.9%`)이다.
- **`Tearstable` vs `TearStable`** — 한국 페이지는 `눈물 안정화™ 기술(Tearstable™)`(소문자 s),
  글로벌 사양은 `TearStable™  Technology`(대문자 S). 어느 쪽이 정정인지 확인하지 못해 각 원문 그대로 뒀다.
  (본 검증의 9개 필드에는 쓰이지 않는 문자열이다.)
- 한국 IFU 목록 페이지 표기 크기(`103 KB`)와 실제 파일(123,424 bytes)이 어긋난다.
  모이스트(`97 KB`/112,074) · 오아시스 2주(`148 KB`/177,029)에서도 같은 어긋남이 있었다. 목록 크기 표기를 근거로 쓰지 않는다.

### 3-5. 교체주기 원문이 형제 제품과 다르다

- 한국 IFU 원문: `1. 일일 착용 콘택트렌즈는 별도의 세척 또는 소독이 필요하지 않다. 렌즈를 제거한 후 폐기하고 새로운 콘택트렌즈 또는 안경을 착용한다.` / `2. 재사용 금지`

- 값 `1일`은 유지하되, `raw`는 위 IFU 원문 문장을 그대로 넣었다.

### 3-7. 콘텐츠 연결 확인

- 이 제품은 파일럿의 **아큐브 오아시스 원데이와 물성값이 거의 동일**하다
  (재질·함수율·Dk/t·중심두께·BC·DIA 전부 같음). 두 제품을 나란히 놓으면
  **"숫자가 같아도 다른 제품"**이라는 사실과, 차이가 UV·기술·포장에만 있다는 사실이 그대로 보인다.
  함수율 글의 `숫자만으로 판단하지 않는다`는 논지에 직접 붙는 사례다.
- 다만 그만큼 **비교표에서 두 제품이 중복돼 보일 위험**도 있다. 편입 시 두 제품을 같은 화면에 넣을지 판단이 필요하다.
- 한국 페이지는 블루라이트 약 55% 차단(옵티블루™)을 주장하지만
  같은 페이지 각주 `±`가 **HEV 차단이 착용자에게 안구 건강상 어떠한 이점도 제공하지 않는다**고 스스로 적는다.
  성능 주장과 물성값을 섞지 않는다는 파일럿 원칙에 따라 **9개 필드에는 넣지 않았다.**

## 5. 편입 시 손볼 것

- `products-entry.js`는 지시에 따라 값이 있는 곳(`uv`)에만 `conflicts`를 넣었고, 빈 `conflicts: []`는 생략했다.
- `id`/`slug`는 `acuvue-oasys-max-1-day`, `selectorLabel`은 `아큐브 오아시스 맥스 원데이`(MFDS 업체 제품 명칭 표기)로 넣었다.
  **한국 공식 제품 페이지의 표기는 `아큐브® 오아시스 MAX 원데이`**이므로 `name`은 그쪽을 따랐다.
  두 표기 모두 MFDS 원장 업체 제품 명칭에 병기돼 있어 어느 쪽도 창작이 아니다.
- **`uv` 필드가 `state: "conflict"`**이므로 비교표 UV 행이 두 원문을 병기하게 된다.
- 편입하면 아큐브 오아시스 원데이와 물성 6개 값이 완전히 겹친다. 비교표에서 두 제품을 어떻게 배치할지 결정이 필요하다.
