# LensFact 후속 디자인 요청 — 콘텐츠 유입 구조와 미래 광고 자리

현재 `LensFact Home V4` 수정은 그대로 유지해 주세요. 이번 작업은 홈페이지를 다시 복잡하게 만드는 것이 아니라, **검색 유입용 콘텐츠 화면을 별도 설계하는 후속 작업**입니다.

LensFact는 포장 숫자 해석기만 제공하는 도구가 아닙니다. 검색되는 전문 글로 사용자를 유입하고, 글에서 포장 해석기·공식 사양 비교·출처 근거로 연결하는 정보 서비스입니다.

이번에는 실제 광고를 연동하지 않습니다. 다만 향후 광고가 들어가도 읽기 흐름과 신뢰성이 무너지지 않도록 **광고 예약 영역의 위치와 크기**까지 디자인에 포함해 주세요.

## 1. 이번 산출물

다음 화면만 새로 디자인해 주세요.

1. 콘텐츠 허브 — 데스크톱 1280px
2. 콘텐츠 허브 — 모바일 390px
3. 글 상세 페이지 — 데스크톱 1280px
4. 글 상세 페이지 — 모바일 390px

홈페이지 V4의 Hero·해석기·비교 영역은 다시 디자인하지 마세요.

새 결과물은 `LensFact Content System V1.dc.html`로 만들고, 기존 V3·V4 파일을 보존해 주세요.

## 2. 콘텐츠 허브 목적

사용자가 검색이나 내부 링크로 들어와 다음 네 종류의 콘텐츠를 쉽게 찾게 합니다.

- `렌즈 숫자 읽기` — BC, DIA, 함수율, 재질, Dk, Dk/t
- `오해 확인` — 함수율이 높으면 더 촉촉한가, 같은 BC면 같은 핏인가
- `공식 사양 비교` — 제품의 공식 표기와 측정 조건을 사실 중심으로 비교
- `포장지·허가정보 읽기` — 포장 표기, 제조사 자료, 식약처 허가정보를 읽는 방법

콘텐츠 허브에는 다음을 포함해 주세요.

- 페이지 제목과 한 문장 설명
- 카테고리 또는 주제 필터
- 대표 글 1개
- 최신·핵심 글 목록
- `포장 숫자 해석하기`로 연결되는 간결한 진입점
- `공식 사양 비교하기`로 연결되는 간결한 진입점

가짜 조회수, 가짜 인기 순위, 별점, 후기 수, 사용자 수는 만들지 마세요.

## 3. 글 상세 페이지 구조

예시 글 제목:

> 함수율이 높으면 더 촉촉한 렌즈일까요?

권장 순서:

1. 제목
2. 두세 문장의 짧은 결론
3. 확인일·편집 원칙·출처 개수 같은 최소 메타데이터
4. 모바일에서도 사용할 수 있는 짧은 목차
5. 본문
6. 핵심 용어 설명
7. 공식 출처와 측정 조건
8. 확인할 수 없는 부분과 해석의 한계
9. 관련 포장 숫자 해석기 연결
10. 관련 공식 사양 비교 연결
11. 관련 글 2~3개
12. 최종 전문가 확인 경계

본문은 검색 유입용 장문을 전제로 하되, 한 문단을 짧게 유지하고 소제목·목록·인용·간단한 비교 요소로 읽기 흐름을 나눠 주세요.

## 4. 출처와 편집 신뢰 표시

글 상단에서는 다음만 간결하게 표시합니다.

- `공식 자료 기반`
- `예시 확인일`
- `편집 해설 포함`

세부 출처는 본문 하단 또는 해당 문단의 `출처 보기`에서 펼칠 수 있게 합니다.

세부 출처 구조:

- 기관·제조사
- 문서명
- 원문 표기
- URL
- 확인일
- 측정 조건
- 출처 간 값 차이

광고, 협찬, 제조사 자료, 편집 해설이 시각적으로 섞이지 않게 분리해 주세요.

## 5. 미래 광고 예약 영역

실제 AdSense 코드, 광고 네트워크, 쿠키 배너, 분석 도구를 넣지 마세요.

회색 박스만 반복하는 광고 보드처럼 만들지 말고, 실제 글의 흐름 안에 다음 자리만 절제해서 표시해 주세요.

### 글 상세 광고 후보

- 도입부와 첫 번째 본문 섹션이 끝난 뒤 1개
- 긴 본문의 중간 소제목 사이 1개
- 본문 종료 후 관련 글 앞 1개

데스크톱에서는 필요하면 본문 옆 보조 영역 후보도 보여줄 수 있지만, 고정 광고가 본문이나 출처를 가리지 않게 하세요.

모바일에서는 인라인 광고만 사용하며 화면을 가리는 sticky·anchor·전면 광고를 사용하지 않습니다.

### 광고 영역 표시 규칙

- 작은 `광고` 레이블을 명확히 표시
- 제조사 공식 자료나 추천 제품 카드처럼 보이지 않게 중립적으로 표현
- 광고가 없어도 레이아웃이 어색하지 않게 구성
- 광고 로딩 전후 레이아웃 밀림을 막을 수 있는 최소 높이 예약
- 광고와 본문·출처·전문가 경계 사이에 충분한 여백 확보

### 광고를 두지 않을 곳

- 홈페이지 Hero와 첫 CTA 사이
- 포장 숫자 해석 결과 내부
- 값과 출처 사이
- 공식 사양 비교표 내부
- 안전 경고·전문가 확인 문구 바로 위아래
- 광고가 LensFact의 제품 추천처럼 보일 수 있는 위치

## 6. 검색 유입과 내부 연결

글을 읽은 사용자가 자연스럽게 다음 행동으로 이동하도록 설계해 주세요.

- 용어 글 → 해당 포장 숫자 해석
- 오해 확인 글 → 관련 공식 사양 비교
- 제품 비교 글 → 각 값의 뜻과 출처 확인
- 포장지 읽기 글 → 전체 해석기 시작

CTA는 구매·예약이 아니라 다음과 같은 학습 행동만 사용합니다.

- `이 숫자 해석하기`
- `공식 사양 확인하기`
- `관련 근거 읽기`
- `두 제품의 공개 사양 비교하기`

`추천 제품`, `베스트`, `나에게 맞는 렌즈`, `구매하기`, `최저가`, `쿠폰` 표현은 사용하지 마세요.

## 7. 시각 방향

홈페이지 V4와 같은 디자인 시스템을 유지합니다.

- Coral: `#F48067`
- Midnight Blue: `#051230`
- White: `#FFFFFF`
- Soft Ivory: `#FFF8F2`
- Pale Blue: `#EAF5FF`
- 본문: Pretendard 또는 SUIT 계열의 읽기 쉬운 산세리프
- 모노스페이스: BC, DIA, `8.6 mm`, Dk/t 같은 실제 사양값에만 사용

글 상세는 장시간 읽기에 적합해야 합니다.

- 데스크톱 본문 폭 약 680~760px
- 데스크톱 본문 17~18px 권장
- 모바일 본문 16px 이상
- 넉넉한 줄간격과 문단 간격
- 출처·광고 문구도 13px 미만으로 축소하지 않기
- 카드와 테두리를 과도하게 사용하지 않기
- 장식용 애니메이션 금지

## 8. 안전 경계

- 진단·처방·치료·개인 적합성 판단 금지
- 제품 추천·우월성·순위 표현 금지
- 구매·예약·제휴 링크 금지
- 광고가 편집 콘텐츠처럼 보이지 않게 분리
- 공식 자료와 편집 해설을 구분
- 확인되지 않은 값은 `확인되지 않음`으로 표시

글 하단에 다음 문구를 유지합니다.

> 최종 적합성·도수·피팅은 안경사 또는 안과 전문인에게 확인하세요.

## 최종 목표

> 검색되는 글로 들어오고, 쉬운 설명으로 이해하며, 해석기와 공식 근거로 더 깊게 확인하는 구조.

광고는 아직 수익 기능이 아니라 **미래에 추가해도 정보 신뢰와 읽기 흐름을 해치지 않는 예약 공간**으로만 설계해 주세요.
