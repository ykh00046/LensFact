# LensFact Claude Design V3 요청 — 가독성과 일반 소비자 사이트 구조

기존 V2는 이전 피드백을 성실하게 반영했지만, 결과적으로 **일반 소비자가 방문하는 웹사이트가 아니라 데이터 검수 도구·내부 명세 화면처럼 보입니다.**

이번 V3의 핵심은 색만 바꾸는 것이 아닙니다. **첫 화면의 정보량을 크게 줄이고, 일반적인 소비자 정보 사이트의 구조로 다시 설계하는 것**입니다.

## 가장 중요한 판단

- 정확성·출처·충돌 처리 규칙은 유지합니다.
- 그러나 그 내용을 첫 화면에 모두 보여주지 않습니다.
- 사용자가 먼저 쉬운 답을 보고, 원할 때 근거와 과학적 세부를 펼치게 합니다.
- V2의 모든 요구사항을 한 화면에 담으려고 하지 마세요.

> 첫 화면은 “이 사이트에서 무엇을 할 수 있는가”만 즉시 이해시키고, 세부 근거는 사용자의 행동 뒤에 보여줍니다.

## 1. 이번 산출물 범위

이번에는 다시 거대한 디자인 보드를 만들지 마세요. 다음 세 장면만 실제 사이트 크기로 보여 주세요.

1. 1280px 데스크톱 홈페이지
2. 390px 모바일 홈페이지
3. 사양 하나를 선택한 간단한 상세 상태 — `뜻`, `주의할 점`, `출처 요약`, `출처 보기`만 표시

비교표 전체, 상태 명세표, 반응형 규칙표는 이번 화면에 넣지 마세요. 홈페이지의 가독성과 분위기를 먼저 확정한 다음 별도 작업으로 설계합니다.

데스크톱과 모바일을 한 캔버스에 동시에 축소 전시하지 말고, 실제 크기로 전환해서 볼 수 있게 해 주세요.

## 2. 홈페이지는 일반적인 소비자 사이트처럼 구성

### 상단 내비게이션

- 로고 `LENSFACT 렌즈팩트`
- `렌즈 숫자 해석`
- `공식 사양 비교`
- `포장지 읽는 법`
- `렌즈 상식`

메뉴는 많아 보이지 않게 정리하고 모바일에서는 일반적인 메뉴 버튼으로 접습니다.

### 첫 화면 Hero

한 개의 메시지와 한 개의 주 행동만 둡니다.

제목:

> 내 렌즈 포장지, 숫자부터 읽어보세요.

설명:

> BC, DIA, 함수율처럼 헷갈리는 표기를 쉬운 말과 공식 출처로 설명합니다.

주 버튼:

> 포장 숫자 해석하기

보조 행동:

> 샘플로 먼저 보기

Hero 오른쪽 또는 아래에는 실제 브랜드를 모방하지 않은 **간결한 렌즈 포장 라벨 한 장**을 배치합니다. 라벨에는 BC, DIA, 함수율 정도만 우선 보이고 Dk·Dk/t·UV·교체 일정 전체를 처음부터 펼치지 마세요.

### Hero 다음

짧은 신뢰 문장 세 개만 둡니다.

- 공식 자료를 출처로 확인합니다
- 확인할 수 없는 값은 그대로 미확인으로 표시합니다
- 제품을 판매하거나 순위를 매기지 않습니다

그다음에는 다음 진입점만 간결하게 둡니다.

- `자주 찾는 숫자` — BC, DIA, 함수율
- `두 렌즈 공식 사양 비교하기`
- `포장지 읽는 법`과 최근 상식 글 2~3개

일반적인 홈페이지처럼 충분한 여백과 큰 제목을 사용하세요. 내부 QA 화면처럼 모든 영역을 가는 테두리로 나누지 마세요.

## 3. 첫 화면에서 보여줄 것과 숨길 것

### 처음부터 보여줄 것

- 사이트 이름과 한 문장 설명
- 주 CTA 하나
- 샘플 포장 라벨
- BC, DIA, 함수율 등 친숙한 대표 항목
- 짧은 신뢰 원칙 세 개
- 전문가 확인 경계 문구

### 누른 뒤 보여줄 것

값을 선택하면 다음 순서만 보여 주세요.

1. 쉬운 뜻
2. 한 줄 주의사항
3. `제조사 공식 사양 · 확인일` 같은 한 줄 출처 요약
4. `출처 보기`

### `출처 보기`나 accordion 안으로 숨길 것

- 출처 유형
- 기관·제조사
- 문서명
- 원문 표기
- URL
- 확인일
- 출처별 충돌값
- 시험 도수·중심 두께·측정 조건
- 함수율 core/bulk/surface 기준
- 제품 식별 연결 근거

상태 범례 5종 전체, 제품 식별 불확실성 설명, 과학 표현 규칙, 반응형 규칙, aria 구현 설명은 소비자 화면에 노출하지 마세요. 이것은 향후 `데이터 원칙` 페이지나 개발 명세에 둘 내용입니다.

## 4. 색상 방향 — 참고 영상 반영

참고 영상:

- `그대로 갖다 쓰는 색깔 조합 16가지`
- https://youtu.be/23kxFVxYZIY

영상의 조합 중 **코럴 + 미드나잇 블루**를 LensFact 기본 방향으로 사용해 주세요.

- Coral: `#F48067`
- Midnight Blue: `#051230`
- White: `#FFFFFF`
- Soft Ivory: `#FFF8F2`
- Pale Blue: `#EAF5FF`
- Border Gray: `#E5E7EB`
- Muted Text: `#5B6472`

### 사용 규칙

- 제목과 본문 기본색: `#051230`
- 주 CTA: `#051230` 배경 + 흰 글자
- Coral: 선택 상태, 밑줄, 작은 강조 영역, 보조 CTA에 제한
- Coral 배경 위 글자가 필요하면 `#051230` 사용
- **Coral 위 흰 글자는 사용하지 않음** — 대비가 약합니다
- 기본 배경은 흰색, 섹션 구분에 Soft Ivory나 Pale Blue를 제한적으로 사용
- 페이지 전체를 Midnight Blue나 Coral로 채우지 않기
- 상태 경고 색은 브랜드 Coral과 별도 의미 체계로 유지하고 텍스트 레이블을 병행

Coffee Brown `#71502F` + Olive Green `#788860`은 차분하지만 V2의 문서·헤리티지 느낌을 더 강화하므로 이번 주 팔레트로 사용하지 마세요. Ivory + Light Sky Blue는 보조 배경으로만 참고해 주세요.

## 5. 타이포그래피와 가독성

- 한국 소비자 사이트에 익숙한 산세리프를 기본으로 사용합니다. Pretendard 또는 SUIT 계열 느낌을 권장합니다.
- 모노스페이스는 BC, DIA, `8.6 mm` 같은 실제 사양값에만 제한합니다.
- 데스크톱 본문 16px 이상
- 모바일 본문 15px 이상
- 출처 요약·상태 텍스트 13px 미만으로 축소하지 않기
- 데스크톱 Hero 제목 약 44~52px
- 모바일 Hero 제목 약 30~34px
- 줄간격을 넉넉히 하고 한 문단을 짧게 유지
- `예시 확인일` 같은 메타데이터를 모든 화면 상단에 반복하지 않기

V2의 10~11px 메타데이터 중심 구조를 가져오지 마세요.

## 6. 컴포넌트와 레이아웃

- 최대 콘텐츠 폭은 약 1120~1200px
- 섹션 사이 여백을 충분히 확보
- 모든 정보를 테두리 박스에 넣지 않기
- 카드 수를 줄이고 하나의 주요 포장 라벨에 시선을 집중
- 선택 가능한 사양은 명확한 button으로 표현
- 모바일 터치 영역 최소 44px
- 긴 출처는 상세 disclosure에서 자연스럽게 줄바꿈
- `자세히 보기`, `출처 보기`로 progressive disclosure 사용
- 출처·충돌·과학적 제한은 숨기는 것이 아니라 사용자가 원할 때 쉽게 열 수 있게 설계

## 7. 유지해야 할 안전 경계

- 추천, 베스트, 순위, 적합 점수, `나에게 맞는 렌즈` 표현 금지
- 진단·처방·치료·개인 적합성 판단 금지
- 구매·예약·쿠폰·제휴 링크 금지
- 광고형 제조사 우월 표현 금지
- 최종 경계 문구 유지:

> 최종 적합성·도수·피팅은 안경사 또는 안과 전문인에게 확인하세요.

## 8. V2에서 가져오지 말아야 할 것

- 상단의 디자인 검수용 화면 탭 5개
- 데스크톱과 모바일을 한 화면에 축소해 놓은 구성
- 홈의 상태 범례 5종 전체
- 홈의 전체 출처 표
- 홈의 제품 식별 불확실성 설명
- 홈의 과학 표현·반응형·접근성 명세
- 모든 값을 가는 선으로 빽빽하게 구분한 표
- 작은 모노스페이스 메타데이터의 반복
- 베이지·회색 문서 도구 분위기
- V2 정보량을 그대로 둔 채 색만 바꾸는 수정

## 최종 디자인 목표

> 전문성은 뒤에서 받치고, 첫인상은 쉽고 밝고 익숙하게.

LensFact가 처음에는 **일반 소비자가 부담 없이 들어오는 사이트**로 보이고, 값을 눌렀을 때 비로소 **공식 출처와 제조·소재 전문성이 드러나는 구조**로 만들어 주세요.
