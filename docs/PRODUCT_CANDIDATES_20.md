## 이 문서의 성격 — 값은 담지 않는다

이 문서는 후보 제품의 **신원(identity)과 공식 출처 위치**만 기록한다.
BC, DIA, 함수율, Dk/t, 중심두께, 허가번호 같은 **수치·식별번호는 의도적으로 수집하지 않았다.**
값은 `다음 단계`의 제품별 검증 절차에서 원문 대조를 거쳐 별도로 채운다.

`docs/REAL_DATA_PILOT_BRIEF.md`의 출처 원칙을 그대로 따른다.

- 한국 유통·허가 식별: 제조사 한국 공식 페이지 · 한국 IFU · MFDS UDI 조회
- BC·DIA·함수율·Dk/t: 제조사 기술 사양서 또는 전문가용 공식 사양
- 지역별 숫자가 다르면 합치지 않고 각 출처의 원문값과 조건을 병기
- 광고성 성능 문구는 물성값과 분리하고 사용하지 않음
- 한국 공식 자료에서 찾지 못한 값은 글로벌 공식 자료임을 명시

## URL 확인 방법

이 문서에 적힌 모든 URL은 2026-08-28에 브라우저 User-Agent로 리다이렉트를 따라가며(`curl -L`) HTTP 상태와 최종 URL을 확인했다.
`✅`는 **HTTP 200이고 최종 URL이 홈으로 튕기지 않은 실제 대상 페이지**임을 뜻한다.
확인하지 못했거나 존재하지 않는 경로는 `❌ 미확인`으로 명시한다.

확인 결과 요약: 이 문서에 실린 **60개 URL 전부가 200으로 재확인**됐고, 한국 공식 제품 페이지가 **존재하지 않는 후보가 2건**이다.

## 다음 단계 — 제품별 검증 체크리스트

`docs/REAL_DATA_PILOT_BRIEF.md`의 출처 원칙에서 유도한 절차다. 제품 하나마다 아래를 순서대로 수행하고, 각 단계의 결과를 원문 그대로 기록한다.

### 0. 준비

- [ ] 대상 제품의 한국 판매명·글로벌명·제조사·유통사를 표 A에서 확정한다
- [ ] 이 시점에는 아직 어떤 수치도 적지 않는다

### 1. MFDS UDI — 한국 유통·허가 식별

출처: https://emedi.mfds.go.kr/msismext/udi/uif/schStddCdLstView.do (✅ 200)

- [ ] 업체명(한국 유통사)으로 전체 조회한 뒤, `modelnm`·`prdtNmCn`·`prdlNm`으로 좁힌다
- [ ] 표 A의 **MFDS UDI 검색 키워드**를 출발점으로 쓰되, 한국 허가명은 판매명과 다를 수 있으므로 여러 표기를 시도한다
- [ ] 허가번호를 **원문 그대로** 기록한다 — `호`가 붙었는지, 하이픈 위치, 공백까지 그대로. (예: `수허 13-112 호`와 `수허 08-131`은 표기가 다르다)
- [ ] 국내 제조 제품(21, 22번)은 `수허`가 아닌 다른 접두어일 수 있다. 추정해서 바꾸지 않는다
- [ ] **조회일·조회조건·일치 건수**를 함께 기록한다 (파일럿의 데일리스 토탈원 방식: "2026-08-27 조회, 한국알콘 전체 46,382건 중 조건 일치 105건이 모두 같은 번호")
- [ ] 같은 허가번호에 여러 모델이 묶여 있으면 그 사실을 기록한다
- [ ] `의료기기심의필` 번호는 **광고 사전심의 번호**다. 허가번호 필드에 절대 넣지 않는다

### 2. 한국 공식 페이지 / 한국 IFU — 유통 근거와 한국 표기값

- [ ] 표 B의 한국 공식 제품 페이지를 열어 **해당 제품 페이지가 맞는지** 확인한다 (홈으로 리다이렉트되지 않는지)
- [ ] 한국 IFU PDF가 있으면 내려받아 허가번호·제품명·교체주기 표기를 원문 그대로 옮긴다
- [ ] 한국 페이지에 수치가 있으면 **글로벌 수치와 합치지 말고 별도 값으로 저장**한다 (아큐브 UV 표기 사례)
- [ ] 한국 자료가 없으면 그 사실 자체를 기록한다 — 나중에 값에 `글로벌 공식 자료임`을 명시하기 위한 근거가 된다
- [ ] 마케팅 문구(`16시간 촉촉`, `하루 종일 편안` 등)는 **물성값과 분리하고 이번 확장에서도 사용하지 않는다**

### 3. 제조사 기술 사양 — 수치의 근거

- [ ] 표 B의 글로벌 기술 사양 URL(전문가용 페이지 또는 사양서/PI PDF)에서 BC·DIA·함수율·Dk/t·중심두께·도수 범위·UV를 가져온다
- [ ] **값만 옮기지 말고 조건을 함께 옮긴다**
  - Dk/t: 시험 도수(예: `at -3.00D`), 측정법, 경계 보정 여부, 온도
  - 함수율: 벌크 / 코어 / 표면 중 무엇인지 라벨에 포함
  - 중심두께: 기준 도수
- [ ] `Dk`와 `Dk/t`를 구분한다. 출처가 어느 쪽을 적었는지 그대로 따른다
- [ ] **교체주기와 착용방식을 구분한다.** `30일`은 교체주기다. 연속착용은 전문가 판단이 필요한 별도 착용방식이며 임의로 수면착용 허용으로 해석하지 않는다
- [ ] 문서에 개정일·버전이 있으면 함께 기록한다 (CooperVision 한국 사양서처럼 파일명에 연도가 없는 경우 특히)

### 4. 충돌 처리

- [ ] 한국 페이지 · 한국 IFU · 글로벌 사양 사이에 값이 다르면 **하나로 합치지 않는다**
- [ ] 각 값에 출처와 조건을 붙여 병기하고 필드 상태를 `conflict`로 둔다
- [ ] 어느 쪽이 맞는지 판단하지 않는다. 화면에서도 숨기지 않는다
- [ ] 예상되는 충돌 지점: CooperVision 계열의 Dk/t와 UV, Alcon 워터 그라디언트 계열의 함수율 기준, 아큐브 계열의 UV 표기

### 5. 확인되지 않은 값

- [ ] 검토한 공식 자료에서 찾지 못한 값은 `unknown`으로 둔다
- [ ] `없음`, `0`, `해당 없음`으로 단정하지 않는다 (파일럿의 데일리스 토탈원 UV 처리 방식)
- [ ] 어떤 자료를 어디까지 확인했는지 메모로 남긴다

### 6. 기록 형식
