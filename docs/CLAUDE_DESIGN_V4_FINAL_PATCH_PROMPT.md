# LensFact V4 최종 수정 요청

V3 방향은 승인 직전 단계입니다. **전체 레이아웃·색상·타이포그래피·정보량·상호작용은 그대로 유지하고 아래 항목만 수정**해 주세요.

새로운 섹션이나 카드, 설명, 기능을 추가하지 마세요. V2처럼 정보가 다시 많아지면 안 됩니다.

## 1. 첫 화면 안전 경계 강화

Hero 아래의 신뢰 문장 세 개 중 세 번째 문장을 다음으로 교체해 주세요.

> 판매·추천하지 않으며, 최종 피팅은 전문가에게 확인합니다

현재 푸터의 전체 문구는 그대로 유지합니다.

> 최종 적합성·도수·피팅은 안경사 또는 안과 전문인에게 확인하세요.

첫 화면에는 위 짧은 문장만 노출하고, 별도 경고 박스나 긴 면책문구를 추가하지 마세요.

## 2. 샘플 데이터 오인 방지

현재 샘플 라벨 아래 문구를 다음으로 강화해 주세요.

> 화면 예시입니다. 실제 제품 정보가 아닙니다.

상세 출처 안의 샘플 날짜는 실제 검증일처럼 보이지 않도록 다음처럼 표시해 주세요.

- `2026.08.27 확인` → `예시 확인일 · 2026.08.27`

예시 제조사, `example.invalid`, 예시 문서도 모두 화면 예시라는 점이 문맥상 명확해야 합니다. 단, 출처 상세의 구조 자체는 바꾸지 마세요.

## 3. 모바일 메뉴 접근성 상태 추가

모바일 햄버거 버튼에 다음 의미가 구현되도록 해 주세요.

- 닫힘 상태: `aria-label="메뉴 열기"`, `aria-expanded="false"`
- 열림 상태: `aria-label="메뉴 닫기"`, `aria-expanded="true"`
- 키보드 포커스 표시 유지

가능하면 버튼과 메뉴 영역을 `aria-controls`로 연결해 주세요.
