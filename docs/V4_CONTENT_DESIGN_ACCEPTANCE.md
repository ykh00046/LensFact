# LensFact V4 + 콘텐츠 시스템 V1 검토

## 결론

- **Home V4: 수용**
- **Content System V1: 수용**
- 추가 Claude Design 반복 없이 Codex 프로덕션형 정적 프로토타입 구현으로 넘길 수 있다.

## Home V4 확인

- 첫 화면 신뢰 문장이 `판매·추천하지 않으며, 최종 피팅은 전문가에게 확인합니다`로 수정됐다.
- 샘플 라벨에 `화면 예시입니다. 실제 제품 정보가 아닙니다.`가 표시된다.
- 출처 요약 날짜가 `예시 확인일`로 구분된다.
- 모바일 메뉴 버튼에 `aria-label`, `aria-expanded`, `aria-controls` 상태가 추가됐다.
- 데스크톱 첫 화면을 실제 브라우저로 열었고 런타임 오류 표시는 0건이었다.
- 기존 V3의 여백, 정보량, 색상, 해석 상세 구조를 유지했다.

사소한 표시 오류:

- V4 파일의 디자인 미리보기 상단 문구가 아직 `LensFact V3`로 표시된다. 생산 화면이 아닌 디자인 도구용 크롬이므로 방향 수용을 막지 않는다. Codex 구현에는 가져오지 않는다.

## Content System V1 확인

### 콘텐츠 허브

- 4개 주제 축을 제공한다: 렌즈 숫자 읽기, 오해 확인, 공식 사양 비교, 포장지·허가정보 읽기.
- 대표 글, 최신 글, 해석기 진입점, 공식 사양 비교 진입점을 분리했다.
- 가짜 조회수·별점·인기 순위·후기를 사용하지 않았다.
- 데스크톱 허브를 실제 브라우저로 열었고 런타임 오류 표시는 0건이었다.

### 글 상세

- 제목, 짧은 결론, 최소 메타데이터, 목차, 본문, 핵심 용어, 출처, 한계, 해석기·비교 연결, 관련 글, 전문가 확인 경계를 포함한다.
- 본문 폭 720px, 보조 영역 300px로 장문 가독성을 확보했다.
- 모바일 본문은 16.5px 중심이며 광고·출처 문구도 13px 미만으로 낮추지 않았다.
- Dk와 Dk/t를 구분하고 측정 조건 미공개 시 직접 비교하지 않는다는 제한을 표시한다.
- 샘플 출처와 예시 데이터가 실제 정보가 아니라고 명시한다.

### 광고 예약 영역

- 실제 광고 코드 없이 예약 영역만 표시한다.
- 본문 도입 뒤, 소제목 사이, 본문 종료 뒤, 데스크톱 보조 영역 후보를 보여준다.
- 모바일은 인라인 후보만 두고 고정·전면 광고를 배제한다.
- 광고 레이블과 최소 높이가 명시돼 편집 콘텐츠 혼동 및 레이아웃 밀림 위험을 줄였다.
- 해석 결과·출처·전문가 확인 문구 내부에는 광고를 배치하지 않았다.

중요한 구현 원칙:

- 디자인에 표시된 광고 후보를 한 글에 모두 활성화하지 않는다.
- 실제 글 길이와 광고 정책에 따라 슬롯을 선택하며, 초기에는 광고 컴포넌트 자체를 비활성 상태로 둔다.
- 광고 슬롯은 편집 데이터가 아니라 별도 레이아웃 설정으로 관리한다.

## 검증 한계

- Home V4와 Content Hub 데스크톱 첫 화면은 실제 브라우저에서 확인했다.
- 두 화면 모두 런타임 오류 표시 0건이었다.
- 이후 별도 브라우저 세션을 병렬로 열어 상세·모바일 상호작용을 확인하려 했으나 Browser Harness가 `WinError 10048` 및 `WinError 52`로 세션 충돌을 일으켰다.
- 상세·모바일 상태는 HTML 소스를 대조해 구조와 핸들러 존재를 확인했으며, 추가 브라우저 실측은 Codex 구현 검증 단계에서 다시 수행한다.

## Codex 인수 조건

1. `x-dc`, `sc-for`, `support.js`, 고정 1280/390 프레임, 인라인 스타일, CDN 런타임을 복사하지 않는다.
2. 실제 반응형 시맨틱 HTML과 최소 의존성 구조로 재구현한다.
3. 콘텐츠·출처·제품 사양을 화면 코드와 분리된 정적 데이터 스키마로 둔다.
4. 목차, 관련 글, 카테고리, CTA를 실제 링크와 버튼으로 구현한다.
5. 키보드 포커스, `aria-expanded`, 모바일 메뉴, 출처 disclosure를 테스트한다.
6. 광고 슬롯은 기본 비활성화하고, 활성화 전까지 네트워크 코드·쿠키·분석 도구를 넣지 않는다.
7. 샘플 날짜, `example.invalid`, 예시 제조사·제품 수치를 생산 데이터로 이식하지 않는다.
8. 장식 애니메이션 없이 150~200ms 수준의 상태 전환만 사용하고 `prefers-reduced-motion`을 지원한다.
9. 추천·순위·개인 적합성·구매 유도 표현을 금지한다.
10. 모바일 390px 및 데스크톱 실제 브라우저에서 주요 흐름을 재검증한다.
