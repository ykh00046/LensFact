# LensFact

한국 유통 콘택트렌즈의 공식 사양을 소비자 언어로 해석하는 검증형 정보 서비스입니다.

## 현재 단계

1. 시각 콘셉트와 콘텐츠 시스템 확정
2. 정적 프로토타입 구현 및 데스크톱·모바일 검증 완료
3. 실데이터 20개 제품 편입 완료 (2026-08-28) + 핵심 글 1개
4. 사실·법적 경계 검수 후 미리보기 배포
5. 검색 색인과 실제 유입을 확인한 뒤 콘텐츠 확대

AdSense는 초기 범위에서 비활성화합니다. 빌드, 운영, 검색 발견, 수익화는 서로 다른 검증 단계로 관리합니다.

## 핵심 원칙

- 제품 추천·처방·진단을 하지 않는다.
- 온라인 주문·결제·배송·구매대행을 하지 않는다.
- 식약처 허가정보와 제조사 공식 사양을 출처와 확인일로 추적한다.
- 공식 사실, 편집 해설, 사용자 체감을 분리한다.
- 파일럿은 실데이터 3개 제품으로 시작하고, 1단계 목표는 대표 투명 구면 렌즈 20개다.
- 회사 내부 자료, 배합, 거래처, 원가, 비공개 사례를 사용하지 않는다.
